Proposal Ammo

The things we have, do, or are about to have that make us the obvious choice — and that are not yet written anywhere in the RFP pages. A notetaker so nothing gets forgotten when the proposal is actually assembled. Anyone can add an item or edit one; every edit is logged below.

How to use it: one card per thing. Say what it is, why it matters to STIHL, and where in the proposal it should land (Where: §6). Mark Status: not yet / partly / in so we can see at a glance what still has to be written. Questions to ourselves go in as Qi:. When an item is fully in the proposal, set its status to in rather than deleting it — the card is the evidence trail.
